# LangFlow Smart Bot – Market Research & Sentiment Analysis

## Project Overview

This project demonstrates the development of an AI-powered Smart Bot using **LangFlow** and a Large Language Model (LLM).

The workflow uses LangFlow's visual, low-code interface to connect a **Chat Input**, **Prompt Template**, **Language Model**, and **Chat Output**. The Prompt Template provides the AI with a defined role and instructions so that user queries can be processed in a structured and meaningful way.

The project focuses on a **Market Research and Sentiment Analysis** use case. The AI is instructed to act as a **Market Research Analyst and Sentiment Analysis Specialist**, allowing it to analyze user-provided text and generate relevant insights.

---

## Objectives

The main objectives of this project are:

- Build an AI workflow using LangFlow.
- Understand how visual AI components can be connected to create an LLM application.
- Use a Prompt Template to control the behavior of the AI.
- Accept user input through the Chat Input component.
- Process user input using a Language Model.
- Generate responses through the Chat Output component.
- Apply role-based prompt engineering.
- Demonstrate the use of LLMs for market research and sentiment analysis.

---

## Technologies Used

| Technology / Component | Purpose |
|---|---|
| **LangFlow** | Visual framework for building and testing LLM workflows |
| **Llama 3.1** | Language model used in the workflow |
| **Prompt Template** | Defines the AI role, context, and instructions |
| **Chat Input** | Accepts the user's query or text |
| **Chat Output** | Displays the AI-generated response |
